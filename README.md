# Retail Business Performance & Order Fulfillment Analytics Dashboard

## Overview

Built an interactive Excel dashboard using 5,000 retail records (Jan 2025–Sep 2026) to analyze revenue performance, product sales, customer segments, sales channels, and order fulfillment efficiency.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- KPI Reporting

## Dashboard Features

- 5 KPI Cards
- 10 Interactive Charts
- Dynamic Slicers
- Product Analysis
- City Analysis
- Channel Performance Analysis
- Order Fulfillment Analysis

## Key Insights

- 40.84% of orders were cancelled or returned.
- Electronics generated 69.04% of total revenue.
- Laptop and Smartphone contributed 60.13% of revenue.
- Kolkata recorded the highest cancellation rate.
- Revenue growth did not improve delivery performance.
